# EEG Biomarker Dashboard: MCI vs Alzheimer's Disease

## Overview
An interactive Shiny dashboard exploring resting-state EEG biomarkers 
that differentiate patients with Mild Cognitive Impairment (MCI) from 
those with Alzheimer's Disease (AD). Data were collected at the 
Goizueta Brain Health Institute at Emory University from 31 participants.

## Live Dashboard
[View the dashboard here](https://youwei-hu.shinyapps.io/dashboard_app/)

## Repository Contents
- `dashboard_app/` — Shiny app source code and data

## Why This Matters
Early and objective differentiation between Mild Cognitive Impairment 
and Alzheimer's Disease is critical for timely clinical intervention, 
yet current diagnosis relies heavily on subjective assessments. This 
dashboard enables clinicians and researchers to interactively explore 
which resting-state EEG biomarkers most reliably distinguish MCI from 
AD, supporting the development of accessible, non-invasive 
neurophysiological tools for earlier dementia detection.
